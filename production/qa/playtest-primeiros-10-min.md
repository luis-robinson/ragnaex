# Teste de jogo — os primeiros 10 minutos (e a primeira hora)

> Criado 2026-11-25 (revisão de diversão). Objetivo: descobrir onde o jogo perde o jogador no começo.
> Quem testa: o ideal é alguém que **nunca jogou**; se for você, crie um personagem novo e jogue sem usar o que já sabe.

## Como rodar
1. Exe atual (`build/windows/RagnaEx.exe`), personagem novo, classe que você menos jogou.
2. Grave a tela (OBS ou Win+G). Fale em voz alta o que pensa ("não sei o que fazer agora").
3. Não use debug, presets nem `--autostart`.
4. Tempo: 10 min com atenção total + o resto da 1ª hora anotando só os momentos marcantes.

## Marque o minuto de cada coisa (tempo até a primeira vitória)
| Momento | Minuto | Observação |
|---|---|---|
| Entrou no mundo (depois do Carregamento) | | |
| Primeiro monstro morto | | |
| Primeira skill usada | | |
| Primeira quest aceita | | |
| Primeira quest entregue | | |
| Primeiro item vestido (melhor que o inicial) | | |
| Primeiro nível novo | | |
| Primeiro ponto gasto na teia | | |
| Primeiro grupo com bot | | |
| Primeira morte | | |

Meta: primeiro monstro antes de 1 min; primeiro nível antes de 5 min; primeiro item melhor antes de 10 min.

## A cada momento de dúvida, anote
- **Confuso**: não sabia o que fazer / para onde ir / o que um botão fazia.
- **Chato**: sabia o que fazer mas não queria (caminhada longa, luta repetida, espera).
- **Frágil**: morreu ou quase, e achou justo / injusto?
- **Uau**: algo que deu vontade de continuar.

## Perguntas no fim da 1ª hora (0-5)
1. Quanto você quer jogar mais uma hora?
2. Você sabe o que cada janela (I C J K L P M) faz?
3. As lutas contra monstros comuns foram tensas ou automáticas?
4. Algum item que caiu te animou?
5. Algum bot ficou na memória pelo nome?
6. Você sabia para onde ir depois de cada quest?
